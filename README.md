🚀 Быстрый старт

npm install
npm run build
npx serve -s build

📝 Подробная инструкция
1. Установка зависимостей

npm install

2. Сборка проекта

npm run build

3. Запуск сервера

# Если serve не установлена:
npm install -g serve

# Запуск:
serve -s build

Приложение будет доступно по адресу http://localhost:3000

📁 Работа с проектом
Галерея изображений:

Создайте папку media в корне проекта

Поместите изображения в media

Создавайте подпапки для организации директорий

Конфигурация:

Настройки аватара, фона и галереи редактируются в App.js

🛠️ Устранение проблем
Ошибки при установке:

# Удалите node_modules и установите заново:
rm -rf node_modules package-lock.json
npm install

Мало памяти при сборке:

npm run build --max_old_space_size=4096

🌐 Деплой
Frontend:

Соберите проект: npm run build

Скопируйте папку build на сервер

Примечание: Для production используйте веб-сервер (Nginx/Apache) для раздачи статики из папки build
